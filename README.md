# Meine Wochenziele – Kugelgläser

Offline-fähige iPad-Webapp im Stil des Unterrichtstimers.

## Bedienung

- Über **ⓘ** oben rechts sind Informationen zu Bedienung, Belohnung, iPad-Nutzung, Datenschutz und Offline-Funktion erreichbar.
- Die Kugeln werden mittig und lückenlos von unten nach oben als **einzelner Stapel** dargestellt. Der Durchmesser wird passend zur Glasbreite und -höhe berechnet.


- Über **⚙️ Gruppe bearbeiten** Namen, Wochenziele und optional eigene Bilder eintragen.
- Unter jedem Reagenzglas eine blau-weiße oder rot-weiße Murmel antippen, um sie hinzuzufügen.
- Bei **10 Kugeln** erscheinen Feuerwerk und Belohnung. Nur das betroffene Reagenzglas wird automatisch geleert. Die anderen Füllstände bleiben bestehen.
- Belohnungen werden pro Kind gezählt. Füllstände, Ziele, Bilder und Belohnungen werden lokal im Browser des jeweiligen Geräts gespeichert.
- Hauptansicht im iPad-Querformat ohne Scrollen; Reagenzgläser stehen immer in einer Reihe. Bis zu 16 Schülerinnen und Schüler werden unterstützt, bei großen Gruppen werden die Elemente entsprechend schmal.
- Um einen Kugelstand zu korrigieren, in den Einstellungen **Kugeln zurücksetzen** wählen.

## Installation

Den **gesamten Ordnerinhalt** (inklusive `icons`) auf einen HTTPS-Webserver / GitHub Pages hochladen. Mit Safari auf dem iPad aufrufen und über **Teilen → Zum Home-Bildschirm** installieren. Nach dem ersten Aufruf über HTTPS ist die App offline nutzbar. Alternativ kann die `index.html` allein im Browser zum Ausprobieren geöffnet werden (ohne verlässliche Offline-Installation).

## Datenschutz

Keine Server-API oder externen Trackingdienste. Daten werden im lokalen Browserspeicher gespeichert. Safari-Daten löschen bzw. App-Speicher löschen entfernt die Daten. Keine Synchronisierung zwischen Geräten. Für die dauerhafte Aufbewahrung ggf. gesonderte Datensicherung einplanen.
